# MouseClickGame

## Overview

MouseClickGame is a 2D underwater-themed game developed using Processing (Java mode) as part of a university programming project.

The project explores object-oriented programming through a game featuring underwater characters, visual assets and interactive gameplay.

## Technologies Used

- Processing (Java mode)
- Java-based object-oriented programming
- 2D graphics and sprite assets

## Project Structure

- `MouseClickGame.pde` — Main game sketcch
- `Animal.pde` — Animal-related code
- `Enemy.pde` — Enemy-related code
- `Friendly.pde` — Friendly-character code
- `Goal.pde` — Goal-related code

## Running the Project

1. Download or clone this repository.
2. Install Processing from https://processing.org/download.
3. Open `MouseClickGame.pde` using Processing in Java mode.
4. Run the sketch.
